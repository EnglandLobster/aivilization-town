# Asset attribution

## tiles.png

Derived from **Kenney "Tiny Town"** (terrain tiles and the building/piece
artwork), https://kenney.nl/assets/tiny-town, license **CC0 1.0** (public
domain, https://creativecommons.org/publicdomain/zero/1.0/). No attribution
required; credit given voluntarily.

The derivation is reproducible: `apps/web/tools/repack-kenney-tilesheet.py`
composes the Kenney tiles onto the layout contract consumed by
`ui/map/tilesheet.js` (terrain row, 7 building bands x 3 reserved upgrade
levels). The agent walk sprites and the selection bracket on the last row are
original placeholder art generated by `apps/web/tools/generate-tilesheet.mjs`
(project-owned, Apache-2.0 like the rest of the repository).

Building "levels" are a local convention (modest -> solid -> grand stone
compositions); they become data-driven when spatial growth (issue #8) lands.
