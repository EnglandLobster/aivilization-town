# 居民生活连续性 v2

状态：六项修复已实现，工程与真实 CLI 验收通过；短时自由模型试运行记录另见验证文档。对应 2026-09-25 社会合理性审查的六项修正。

## 自主性边界

规则约束身份、资源、真实时空与明确同意，不规定居民目标、情绪、信任、社交频率或必须完成的剧情。允许晚到、忽略、撤回、部分参与与和解；记录实际发生的事实，不把这些选择一律拒绝。非正式交流、赠送和自由文本继续独立可用。

## 归属与交付

- information：个人群消息阅读回执，只标记实际返回的消息，分页不跳过未读；退出后的亲历保留。
- memory：私人认知 v2 支持自主置顶和人物关联，256 限额仅约束活跃条目，归档原文保留；旧 v1 限额语义保留。经历检索支持人物、地点、来源与时间。
- openSociety application：将授权读取原文记录为去重的个人经历，保留来源、原文、获知时间和发生时间；超出返回预算时不得制造已读。上下文分别预留待决事项、约定与未读消息的空间，不生成重要性分数或强制响应。
- services v2：新预约区分需提供者参与的服务与自助设施。提供者自主开始服务并占用真实时间；迟到可参加，记录实际参与时长。v2 时段结束为 ended，不能冒充完整履约。旧 v1 事件和状态保留。
- commerce：新增双方可提出、对方独立接受的版本化和解，明确退还及释放剩余托管的分配；拒绝不改变资金。服务报价可显式选择远程交付，商品仍需真实同地交付。旧报价继续同地语义。
- society/content：独立、版本化的自然日生活参数和已定居初始化方案；初始化原始事实明确标注，世界本金与库存计入种子，不伪造亲历或强制目标。canonical 与旧实验参数不变。保留 newcomers 场景作对照。
- residents：CLI/Skill 同步可发现入口；普通 init 默认采用新生活参数及 settled 场景，旧 manifest 不静默迁移。

## 验证

覆盖阅读去重/分页/权限/预算、分类上下文、归档与置顶、服务迟到与提供者时间、旧服务回放、和解双方授权/版本冲突/资金库存守恒、远程交付边界、自然日参数及确定性初始化。完整 lint/typecheck/test/build 后执行真实 CLI 验收。

长期自然涌现与万人规模另行验证，不作为本轮修复已经完成的结论。不新增药理或强制行为脚本。

## 具体语义与版本

- 接口为 resident-cli-v4 / town-resident-skill-v4，能力目录 open-capabilities-v5；161 个命令、35 个组、55 页 Skill。新增命令为 services start、bookings leave、orders propose-settlement/respond-settlement、schedule configure。
- communication 的新增 GroupMessagesRead 是个人精确消息集合，不以最高序号跳过分页空隙。成功的原文读取按稳定来源去重；返回内容超预算时拒绝本次读取，不提交已读或经历。
- resident-attention-v2 对 decisions/appointments/messages 轮流取项，总计最多6条，各区给出 total/shown。区内按已有期限、时间和稳定ID排序；不产生重要性评分、情绪或自动接受。
- resident-cognition-v2 对活跃条目计数（上限256），归档仍可读；pinned 与 people 由本人设置，未传入时保持原值。v1 限额保留。固定事实检索不依赖模型会话历史。
- resident-services-v2：appointment/course 默认 hosted，其他默认 self-service。hosted 提供者先实际 start；course 不允许伪装为无人授课。提供者可选择 until，居民可迟到、选择较短 until 或 leave。ended 记录 attendedMs/providerOverlapMs，不认证主观服务质量。交通 leave 不能用来终止实际旅途或瞬移。
- 提前离场由 world 校验与原参与预留完全匹配，再记录 ResidentParticipationEnded（resident-participation-end-v1）；独立 reducer 应用最终时间事实，不放宽原有 AgentActivityTimeCommitted 的重叠保护。
- order-settlement-v1：任何参与者可提出剩余托管的退款金额与原始条款；另一个参与者接受当前精确版本才结算。余款给卖方，未交付库存退卖方，已交付库存不自动撤回。退款或其他修改使旧提议失效；拒绝/撤回不动资金。没有自动主观裁判，对方不回应也不会被当作同意。
- 远程交付只支持显式 remote 的服务报价；商品和旧报价的实际交付位置语义保留。远程交付文字仍是声明，买方决定是否认可。

## 自然日校准

resident-natural-day-v1 为实验假设，不是现实人口的经验拟合值，也不规定作息。

| 参数                   | 新实验                                               |
| ---------------------- | ---------------------------------------------------- |
| 一天                   | 86,400,000 模拟毫秒                                  |
| 所有住宅的身体上限     | 100；住房不放大生命/精力容量                         |
| 睡眠恢复               | 每小时12.5点，另有每小时1点基础消耗                  |
| 劳动消耗               | 每小时精力5、饱腹3                                   |
| 基础消耗               | 每小时精力1、饱腹2                                   |
| 治疗                   | 每小时恢复40健康、花费20货币；无具体药理             |
| 工资报价               | 对应8小时劳动，实付按劳动时长比例计算                |
| 后台机会默认间隔       | 15分钟；居民可改为1分钟至1天，也可自主等待到具体时间 |
| 每次机会的调度时间成本 | 1分钟，属于显式实验参数                              |

劳动比例计薪由 society 的 LaborPayPolicy 计算，world 编排国库/企业付款与税；WagePaid 记录策略和劳动时长，旧事件不重新计算。毛工资具有分段可加性，净收入仍受已有税制和支付方偿付能力影响。

## 初始化与兼容

普通 `pnpm residents init` 使用 continuity=true + settled：确定性种子组合生活偏好、行为倾向、交往倾向，提供初始资金/食物、部分公共职业和双向熟人ID。熟人仅表示认识，不设置信任或感情，也不生成虚假经历。住房与地点使用场景合法分配，供应来源在上下文说明。

`--initialization newcomers` 保留陌生人起步对照；`--legacy --initialization newcomers` 使用旧世界参数。库函数为已有调用保持 legacy 默认，新代码用 createOpenSocietyManifest({continuity:true}) 显式启用。旧 manifest、已有 journal、canonical 参数不被覆盖，新策略需要新实验目录。

阅读回执、和解和个人间隔是可向现有运行追加的新能力；既有预约 v1 完成语义与认知 v1 限额按其原策略保留。旧记录不会伪装成已在新参数下运行。
