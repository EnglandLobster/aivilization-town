# P2–P6 实施契约 v1

本文件细化 RESIDENT_LIFE_CAPABILITIES_V1.md 的剩余交付范围。状态以实际验收记录为准。

## 边界

- P2 communication 属于 information：群、邀请/申请、成员权限、原始消息、屏蔽与个人提醒偏好。群和信息空间独立，旧 space.members 不变。
- P3 collaboration：版本化多方提议与明确同意。既有 world.socialCommitments 是对话推断的单方承诺，只读查询保留来源标记；不将其悄悄转换为多方合同，也不重复写入旧承诺。
- P4 commerce：报价、订单、付款请求、押金与结算决定。world 作为账户/库存事务边界执行平衡交易；所有方需独立授权。
- P5 services：有限容量的资源时段、预约、排队与到场。容量占用来自实际 accepted booking，不由文案决定。
- P6 society：居住与生活关系、照护、病历授权和学习参与；复用 world 的住房、移动、治疗、教育与治理规则。课程/就诊/交通都需要实际时间与地点。

## 通信

群只有创建者初始入群。邀请由目标接受，申请由群主接受。重复的同向待处理申请幂等；已处理邀请不重复生效。成员上限 100，原文最长 8000 字符。所有成员变更检查群 revision。群主先转让再退出，或者关闭。关闭禁止发送和加入，已有成员可读历史；退出成员不能读取任何群历史。屏蔽阻止新私信和邀请，并在群消息和订阅动态中隐藏被屏蔽者，不删除原始事件。个人可关闭私信唤醒和订阅上下文提醒。

## 提议

所有参与者必须存在且互不重复，上限 20 人，条款最长 8000 字符。发起人创建表示其对该版本同意；其他人各自回应，全部同意才 accepted。修订条款重置其他人同意，拒绝/撤回/过期终止该版本。已接受合同保留，履行/争议是带作者原话的声明，不自动扣款、裁定或改变人格。

## 交易

报价绑定卖方、商品或服务、数量、单位价及版本。下单不扣款；卖方接受时检查/预留库存，买方支付时转入订单托管，交付后买方确认才释放。取消释放预留并按状态退回托管；部分退款不得超过实付。服务交付属于卖方声明，买方确认表达认可。争议暂停自动结算。付款请求与多人分摊各自付款，不能代表别人扣款；押金单独托管并由明确规则释放。金额必须 finite 且大于零，普通交易 moneySupply 不变。

## 时段与生活切片

资源时段使用模拟时间；半开区间 [start,end) 检查重叠总容量。预约/队列不能自动移动居民。签到要求当前真实地点、未处于途中/其他忙碌活动，预约到期按事件收口。取消释放容量。租约使用双方确认、合法住房容量和真实押金/租金；不得把公共住宅地块的任意居民当成土地所有者。家庭关系须双方确认，监护与照护任务分别授权。病历正文与访问授权独立保留，药物不能由自由文本制造身体效果。学习与医疗沿用既有 world 命令及 simulation time，作品原文走 files。公共事务命令接入已有 petition/matters 权威。

## 感知、兼容与验证

新功能用独立可选状态和版本化 policy，旧 manifest 不隐式开启；显式启用事件可重放。居民通过分组 CLI list/read 查询全文；默认只提供最多 6 条本人待处理事项元数据，最新事件优先，同序号按 ID 排序。仅开放居民活动循环可见，不注入 canonical planning。测试覆盖权限、同意、并发版本、拒绝原子性、金额/库存守恒、容量边界、跨时间边界、重放、旧状态兼容。真实模型验收与固定子进程测试分别记录。

### 当前未建模的范围

本次实现的是上述首版生活能力。出生/遗传/儿童成长、药品库存与具体药理、私有土地/产权登记、自动裁判主观服务质量，均没有已定义且验证完成的世界规则，因此不提供伪成功命令。药物与监护相关自由原文可记录，但其主张不能直接变成身体或权限事实。这些是后续独立机制，不能把新增 CLI 数量当作已经模拟所有现实生活场景。

### 策略、回放与部署

- communication-v1、collaboration-v1、resident-commerce-v1、resident-services-v1、resident-life-v1、resident-leases-v1 分别钉住边界。
- 新 manifest 记录完整参数及 provenance；旧 manifest 可省略所有新字段。enable-life 原子追加启用事件和世界策略参数，不改旧文件。
- world 的 ResidentCommerceCommitted 存最终领域事实、平衡 transactions 和库存转移；ResidentLeaseChanged 存最终租约事实。reducer 不重算报价、租金或合同决策。
- ResidentParticipate 是预约/照护应用端口的内部活动类型，不加入 canonical LLM action synthesis。移动、正式学习和医疗仍走原命令。
- 租约推进先枚举模拟租金/到期边界，在每个边界推进原 world 时间规则后再结算；合并时间与逐段推进有等价测试。
- 默认最多 6 条 lifeInbox 元数据，按模拟时间降序、kind/ID 稳定打破平局；只开放居民活动机会可见，无正文摘要、重要性评分或自动唤醒。已退出的私人群不进入上下文。
- 独立实验仍是单写入 journal；领域和世界事件可重放，但没有声称新合同跨分区迁移已支持。
