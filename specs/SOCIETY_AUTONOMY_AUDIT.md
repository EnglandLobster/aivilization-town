# 自主性与外生供给审计

2026-10-05，B02/W01/G01 的持续审计；不是已完成声明。

## 当前自由实验实际使用的边界

`openSociety/manifest.ts` 通过 `openWorldPolicies` 选择既有世界策略，`rhythmPolicy.ts` 改变实际劳动计薪和生理时间尺度。开放居民没有调用候选动作 planner；行动来自身份绑定 CLI。时间推进仍执行到期、供给、公共制度和身体后果，这些不能一概移交模型。

实际 manifest 的 worldPolicies 没有 lifecycle、migration、housingConstruction：本次配置没有启用强制退休、自动迁出、自动选择建设者。消费参数用于居民操作及耐用品到期，不等于存在自动消费决策。不能仅看策略名就指认越界。

## 已确认仍存在的初始制度与外生供给

| 机制                       | 实际来源与后果                                                              | 与原目标的关系                                                                                     |
| -------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 公共地点、住房与岗位       | scenario 种子及现有 world policy；newcomers 仍有初始居所                    | 是外生条件，不是居民建造或经营。岗位资格包含住房等级，属于初始制度而非生理事实                     |
| 初始现金、车辆、设施       | manifest 明确种子                                                           | 可用于探索，但不能计作居民自主生产                                                                 |
| 公共市场及镇外供应         | AMM 储备与 externalMarket/externalTrade                                     | 可作为明示的镇外经济；不能把自动补充当作居民供给闭环                                               |
| 生理救济物资               | timeAdvance 的 `appendPhysiologicalSafetyNetEvents` 产生 `SafetyNetGranted` | 现有默认可直接补充指定库存，缺实际供应方。与严格物资来源要求有差距，不能称作居民互助或有限公共采购 |
| 求职、住房、医疗与教育门槛 | 既有纯规则及公共财政端口                                                    | 已有机制并不代表居民能修改制度；治理入口未齐仍是 G01/G02 待完成项                                  |

## 后续实现必须遵守

新自主运行配置应显式版本化，保留身体衰退、实际投入、权限和有限资源，移除替居民作目的性选择的调度。外部供给必须注明来源与边界；无来源的物资救济不能继续伪装成守恒内生生产。居民自愿的协助、真实公共采购和公共制度选择分别接入自己的领域。

不直接改旧 manifest，不重解释旧事件。既有自由实验保留原配置作为基线，修复或新配置另记。参数来源、启用条件、查询入口和真实后果需要同时更新，不能只在报告中宣称“无预设”。

当前运行中的短实验先观察实际采用与失败；本审计只依据当前源码和 manifest，尚未断言救济物资在此次实验已触发，也不据此否定现有自主通信证据。

## 自由实验中的实际时间语义

基线 journal 第197条（sim 1080000）：居民选择睡眠28800秒。规则立即将能量29.288提高到100，同时预留活动到sim 29880000；回执明确标记 `settlementTiming: effects-at-commit`。这不是模型伪造，也不是已经实现“按已睡时长恢复”。

既有 world 基本行动仍使用预付效果/独占时间语义，而新增服务采用实际参与时长结算。两条通道的假设不同，需要在完整生活能力中显式统一或版本化区分；不能只完成新的服务聚合就宣称全部身体活动按实际时间发生。下一阶段应审计睡眠、劳动、生产、学习、治疗、交易等各条时间后果，保留旧模式回放，新自主模式支持实际进度和明确中断。
