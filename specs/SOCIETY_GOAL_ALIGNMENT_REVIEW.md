# 原目标对照与持续反思

原目标：提供可组合的元能力和可靠的世界规则，让居民自主决定目的、关系、组织与制度，并通过真实行动构造和维持社会。完整范围仍以 `AGENT_DRIVEN_SOCIETY_CAPABILITY_CONTRACTS.md` 的 25 项契约为准。

## 固定检查时点

每个能力阶段验收后、每次真实 Agent 实验后，以及开发方向改变时检查一次。连续两个工程阶段没有新的 Agent 使用证据时，下一阶段先安排实际实验或明确记录无法实验的真实阻塞，不能继续靠增加规则测试推迟。

每次记录五点：本阶段给居民增加了什么自由；哪些真实后果仍由规则约束；有没有替居民决定目的/伙伴/组织；当前最限制社会形成的缺口；下一步如何用实际事件验证而不指定社会剧情。

工程正确、提示式模型操作、无剧情自主采用分开报告。模型说自己建立了组织不算真实建立；没有使用某项能力也不自动证明能力无价值。需要检查可发现性、资源条件、时间机会、权限、成本和拒绝链。
