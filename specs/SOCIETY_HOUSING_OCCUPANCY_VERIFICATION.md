# 居住事实与本人退住：H3接入切片验收

完成住房H3中的实际居住、当前许可和本人退住衔接；H3完整服务供给、企业资产归属、H4公产建设、H5长期责任和H6全运行模式仍在交付范围内。

society拥有个人居住版本与退住决定；world绑定认证居民及其实际登记住所。现有换房、租约入住通过统一AgentResidenceChanged事件推进该版本。新增显式occupancy模式不改变现有住房；旧事件与manifest保留旧语义。退住将住所登记设为明确null，避免旧快照的“人在住宅就推断居住”回退把已退住者重新登记。

CLI `housing occupancy`分开呈现本人住所、身体所在地、物理可用性、当前使用权限、登记容量和个人相关合同引用。`housing leave`只释放本人精确住所/版本的登记，不传送、不删租约、不退款、不免债、不改服务等级或身体。原文和其他人的合同仍由各自权限控制。

验证：

- 5项新增domain/world/worker测试通过。真实组合链使用8份Wood和480000ms劳动建成2人容量住宅，独立接受居住许可不会自动入住，实际移动并选择后才登记。许可到期保留居住事实并显示待处理权限；本人退住释放登记，不能再借旧居住事实重新取得权限。
- 旧地址离开再返回推进版本，旧确认不能复用；未知居民和冒名字段拒绝。旧隐式住所退住后保持null，回放一致。
- 本人退住保留独立私人租约、押金及后续租金义务。此前定向用例因测试材料负重超标被真实出行规则拒绝，改用可合法携带自身材料的两名居民，不削弱负重规则。
- `pnpm check`通过：2813项测试通过、1项跳过；407测试文件通过。全传递依赖build通过。
- 认证HTTP/编译CLI11次调用，5次预期拒绝，包含真实出行、重新登记、旧版本/冒名拒绝，完整状态与journal回放一致，原manifest字节不变。

这是可用工程能力，不是居民自由采用证据。进行中的free-384之后实验冻结在H1/H2版本，不含此切片，不能把该实验行为归因于occupancy代码。
