# 显式组合能力运行配置

上一轮正式daemon实际运行时，居民查询劳动和企业服务收到not-enabled。这是初始化组合缺口，不是需要再造劳动或服务规则。新增`pnpm residents init --root NEW_DIR --profile society-integrated-v1 --count N --initialization settled|newcomers`，把已有manifest工厂的显式可选能力以固定发布清单组合。旧默认、--legacy与旧目录不变；profile只允许init使用，未知名称或与legacy冲突在打开目录前拒绝。

配置归worker composition root，不归任何领域聚合。runProfile.ts列出全部当前可用工厂开关并复用原版本化启用/种子端口，没有动态枚举未来字段或新的世界公式。新特性必须审查配置版本，不能因加了一个boolean就自动进入旧profile。manifest.provenance.runProfile记录版本，原各领域来源、初始资源/机构、worldPolicies继续保留；居民通过原rules.capability/read查询来源，不增加默认上下文或384条命令。

范围：信息/认知/共同记录、集体/账户/程序、真实材料/施工/设施/运输、实际身体/学习/劳动/供给、组织主体/控制/交易/周期责任和现有公共程序/采购。此配置不是25项全部交付，更不是预造居民组织；未接入manifest的遗产/整体清算/全分区等缺口继续保留。初始公共权力、车辆、土地、课程与设施必须仍标为场景来源，不伪造居民投票或劳动。启用功能不授予他人的身体同意、私人记录、资金或治理权限。

组合验收不止检查true标志：打开实际Runtime，查询此前not-enabled的入口，核对来源、独立权限和资源账户；验证实际学习不预付效果与真实时间、旧默认仍保留、完整回放和manifest不变。通过编译CLI初始化并由正式daemon读取同一目录，真实模型自由活动另行报告。不能把profile启动成功当作所有业务组合或稳定社会已验收。

本切片只建立新世界的显式配置，不将已有实验自动升级。已有世界继续逐项enable及兼容预检；全量迁移需要保持活动、旧义务与原始资产，另行验收。完整canonical/分区、住房公共建设、长期责任和自由条件对照继续原总目标。
