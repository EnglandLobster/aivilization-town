# 空间使用权、控制交接与真实占有

本规范展开 W05 的权利路径，连接 W02、W03、W06、M06、M09。开发中；收费、控制权有偿交割、长期义务和所有运行模式仍属于完整交付范围，不能用本基础模块替代它们。

定期许可基础已实现并通过工程门禁，详见 [验收记录](SOCIETY_PREMISES_RIGHTS_VERIFICATION.md)。收费与交割闭环继续开发。

## 1. 边界与归属

premises 拥有建筑及其定期使用许可；authority 验证当前控制主体；society 继续拥有租住合同、实际居住和家庭关系；materials 拥有现场物品。world 编排事实和权限，不能用“许可已到期”生成搬家、没收、拆除、满意或劳动事件。原创建者身份不是永久控制权，建筑控制也不表示拥有公共土地。

居民决定用途、使用人、共享或排他方式、期限、原始条款和价格。代码只执行明确接受的范围。合同原文不是可执行脚本，也不能凌驾于当事人同意、已存在的权利、真实容量或物理状态。

## 2. 定期许可聚合

`resident-premises-rights-v1` 使用独立的 PremisesRights 聚合及 journal 事件，位于 premises 包。旧世界没有此聚合时，原权限规则不变；显式启用只创建空聚合，不重新分配土地或建筑。

每份许可固定：建筑 ID、签发时控制主体与版本、接受主体、实名使用人列表、scope（entry / operate / store / reside）、shared 或 exclusive、startAt/endAt/acceptBy、原文、创建者与独立接受回执。operate/store/reside 同时允许进入，entry 本身不授权生产、存入新物品或迁入。使用人名单不表示其本人同意参与工作或搬家；相关操作仍由本人执行。

shared 表示可以申请实际可用容量，不承诺独占设备。exclusive 仅在明确 scope 和时段内排除其他人的新增使用，不能越权限制别人的其他 scope；entry 只允许 shared。多个相冲突的 accepted 排他时段不能重叠。签发报价不占用权利，接受时再次检验全部冲突及真实义务，防止并发双重授予。

状态：offered → accepted → expired / released；offered → withdrawn / expired。双方可撤回未接受报价。接受须由被授予主体独立执行，且原控制版本仍相同。已接受的期限和使用人固定，不能单方改文或撤销。受让方可以放弃自己的未来许可，但已有实际活动必须先结束；任何有偿关联还须按其退款/终止程序办理。新建另一份许可不能暗中改写旧许可。

已接受许可绑定建筑，控制权交接后仍有效。关闭、拆除、改变用途或缩减已承诺设施，必须先处理尚未到期许可；正常老化不会因合同存在而停止。维护不生成更多权限。物理损坏与合同责任分别记录，后续有偿结算不能把不可用期间伪装为已经提供。

## 3. 真实执行与时间

所有进入、迁入、生产、服务和新存放路径共享 world 的只读使用权检查；静态 ACL 或当前控制者不能绕过 active exclusive 许可。租约和实际居住按 society 的事实保留。授予排他居住权前必须排除冲突租约和现有占有；授予排他存放权前必须排除其他控制者的实物/预留；授予排他经营权前必须排除跨越其开始时间的已预留劳动。

身体活动在开始时验证整个申请时段都被授权，不能用一次短许可占用全天。结束时结算已经授权且确实发生的时间区间，不能以“现在刚好到期”抹去前一段劳动。逐边界推进与大步推进必须得到同样结果。

许可到期阻止新的受保护使用，但不传送人、不删除现场库存、不撤销真实经历。拥有或合法管理现场库存者保留取回入口；该入口只允许进入和取出，不能继续投料、生产或接待。实际居住的退出与救济由租住/治理程序完成，不能借权限布尔值直接赶人。

## 4. 权利收费与交割的后续闭环

commerce 引用 premises 的真实许可事实，独立收款同意和托管。有效使用期间、设施可用期间、实际劳动时间是三种事实，价格依据必须明确；不得混用。付费许可接受与资金托管要原子提交，未付款入口不得先领取权限。

资源控制出售则绑定对应 authority 移交，确认付款和交接同一提交；保留既有许可、租约、实物、债务及其查询路径。公共土地初始制度不能被这一路径私自改成所有权。延期、续约、转许可和解除须新的明确授权，不能默认无限续费。

长期付款继续在各自义务聚合结算，继任、清算、欠付和公共救济属于总 Spec 的同一范围；此许可聚合不另建租金或银行贷款账本。

## 5. 可见性与验收

CLI `permits` 提供规则、分页列表、原文与回执查询、提出、接受、撤回和放弃。集体只能通过绑定精确操作的决定行使控制权或接受权；成员名册不能代替授权。查询向签发/受让主体当前成员和实名使用人开放，地点查询只暴露本人的权限与到期边界，不广播他人合同。

常态上下文只给入口，原文通过主动 CLI 查询；行动回执带 ID、版本、scope、时段与真实结果。固定输出预算和排序，退出私有组织不能继续读取其许可原文。

验收覆盖：独立同意、控制版本变化、集体授权、非有限时间/范围、共享/排他冲突、既有租约/占有/库存/劳动冲突、当前控制者旁路、过期边界、取回实物、已完成劳动、权利随资源继承、旧状态、重复提交、确定性回放、真实 CLI/HTTP 与恢复。付费权利和全模式接入在独立验收完成前明确保留为未完成。
